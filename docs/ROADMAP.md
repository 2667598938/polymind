# 路线图

原则：每个版本只解决一类问题，功能必须能被验收，不堆"看起来很强"的空壳。

## V0.1 MVP（当前）

**主题：能接入、能干活、能收住。**

- 三类协议适配 + 自定义 baseURL
- 六个内置工具 + ReAct 循环 + 步数上限
- 路径牢笼 / 命令白名单 / 三级审批
- SQLite 会话 / 用量 / 审计
- MCP stdio 接入
- 导出 Markdown、CLI 兜底

**出口标准**：`cargo test` 全绿；DeepSeek、Claude、Gemini 各跑通一次带工具调用的会话；Windows 安装包可启动。

## V0.2 可用性（4—6 周）

**主题：让非工程用户也能顺畅用。**

- 供应商预设模板（DeepSeek / 豆包 Ark / 通义 / Moonshot / 智谱 / OpenRouter / Ollama），一键填 Base URL；
- 文件树 + 写入前 diff 预览（改前确认，而不是只给审批弹窗）；
- 图片/截图输入（视觉模型）；
- 项目记忆：把仓库结构、约定写成 `POLYMIND.md`，自动注入系统提示；
- 会话分页加载、会话内搜索；
- 密钥升级为 DPAPI / Keychain 绑定；
- 自动更新（仅上报版本，不采集使用数据）。

**出口标准**：首次配置 3 分钟内完成；1000 条消息会话滚动不掉帧；diff 预览误判率 < 5%。

## V0.3 复杂任务（2—3 个月）

**主题：从"单轮执行"到"多步项目"。**

- 子代理：探索/实现/验证三类角色，主代理只做编排与验收；
- 任务模板（重构、修 bug、写测试、生成报告），模板只改提示词不改权限；
- 检查点与回滚：每次写文件前留快照，支持一键撤销本轮改动；
- 并发工具执行（仅只读工具），写操作仍串行；
- 远程 MCP（streamable HTTP / SSE），带域名白名单。

**出口标准**：10 个真实任务样本，完成率 ≥ 70%，平均人工干预 ≤ 1.5 次。

## V0.4 团队与分发

**主题：让一个团队用同一套策略。**

- 只读策略模板：白名单、审批模式、模型清单可导出为 `policy.json`；
- 多工作区与项目切换；
- 本地用量看板（按天/模型/项目）；
- 可选云同步：端到端加密的会话备份（默认关闭）。

**出口标准**：策略文件在 3 台机器上行为一致；同步包无法被服务端解密。

## 长期（不承诺时间）

- IM 入口（飞书/企微机器人）复用同一内核；
- Linux 桌面（AppImage 已在 CI 构建，未做体验优化）；
- 企业内网网关模式：无外网时全部走自建 one-api；
- 插件签名机制（MCP server 哈希白名单）。

## 明确不做

- 代码补全 / LSP；
- 云端托管执行；
- 代售 token 或积分；
- 移动端原生客户端。
