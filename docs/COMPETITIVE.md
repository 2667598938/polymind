# 竞品分析：桌面 Agent 的四种做法

> 调研时间 2026-11。价格与额度随厂商政策变动，引用处已标注来源。

## 1. 直接竞品

| 产品 | 厂商 | 形态 | 定价 | 模型策略 | 执行能力 | 主要短板 |
| --- | --- | --- | --- | --- | --- | --- |
| **Trae / Trae Work** | 字节 | AI IDE + 工作空间 | $10/月（约 2000 积分），可追加 | 平台统一调度，积分消耗不透明 | 读写代码、构建、多 Agent | 免费额度排队；模型不可自选；国内版与国际版能力割裂 |
| **Qoder / Qoder Work** | 阿里 | 桌面 Agent 套件 | $20/月 2000 积分，追加 $20/1000 | 平台托管，任务成功率优先 | 文件整理、数据处理、浏览器/桌面控制、定时任务 | 单价最高、积分烧得快；官方称后续才允许自带 API |
| **WorkBuddy（CodeBuddy 办公侧）** | 腾讯 | 桌面办公 Agent | 58 元/月 2000 积分 | 混元/DeepSeek/GLM/Kimi 等混合调度 | 目录授权读写、文档/PPT、IM 远程 | 目录一次性授权，安全边界粗；分析稳定性口碑分化 |
| **Cursor** | Cursor Inc. | AI IDE | $20/月起，信用制 | 多模型可切 | 代码库索引、Composer、Agent | 必须换 IDE；信用额度不可控 |
| **Claude Code** | Anthropic | CLI Agent | $20/月起 / 按量 | 仅 Claude | 全仓库推理、终端原生 | 单模型锁定；无 GUI；国内网络门槛 |
| **Cline / Continue** | 开源社区 | IDE 插件 | 免费 + 自付 token | BYOK 全开放 | 读写文件、终端、MCP | 需自己配；无独立桌面体验；审批体验粗糙 |
| **PolyMind（本项目）** | — | 独立桌面客户端 | 软件免费，token 自付 | BYOK，任意兼容网关/本地模型 | 6 内置工具 + MCP，本地执行 | MVP 功能面窄；无编辑器；生态从零开始 |

## 2. 价格与成本结构

公开横评给出的综合单价（每 1k 积分折算美元）大致是：WorkBuddy ≈ $4.15、Trae ≈ $5.00、Qoder Work ≈ $10.00，均显著高于"直连上游按量付费"。原因不难理解：订阅制把模型成本、云资源、平台研发都打包进了积分。

按量直连的量级参考（以公开单价估算，实际以各厂商为准）：

| 任务类型 | 典型 token 量 | DeepSeek 类单价 | Claude/GPT 旗舰单价 |
| --- | --- | --- | --- |
| 单文件重构（读 3 文件、写 1） | 15k in / 2k out | ≈ $0.003 | ≈ $0.08 |
| 跑测试并修 2 轮 | 40k in / 6k out | ≈ $0.008 | ≈ $0.21 |
| 全仓调研 + 报告 | 150k in / 15k out | ≈ $0.03 | ≈ $0.75 |

结论：**"贵模型做难任务、便宜模型做日常"这种分层调度，只有在 BYOK 下才成立**。积分制产品天然反对这种用法。

## 4. 用户为什么会换

不是"PolyMind 功能更多"——短期内不可能。真实替换动机只有三条：

1. **省钱且可控**：同一个任务，用便宜模型跑，账单看得见；
2. **合规**：代码与文件不出本机，只把必要上下文发给模型（甚至可以只走内网网关）；
3. **可改**：公司要加内部工具，直接写个 `Tool` 或接 MCP，不用等厂商排期。

## 5. 我们不具备的优势（必须承认）

- 没有代码索引与语义检索，大仓库定位能力弱于 Cursor/Trae；
- 没有内置编辑器，改完要看 diff 得切回 IDE；
- 没有插件市场与专家模板，冷启动体验更"素"；
- 没有云端算力，长任务受本机限制。

因此 V0.1 的策略是**做窄**：把"接入 + 执行 + 审批 + 记账"做扎实，不追功能数量。

## 6. 借鉴与规避

**值得抄的**：
- Qoder Work 的"中间文件统一落本地、可检查"——我们用工作区 + 审计表实现；
- CodeBuddy 的记忆/日程式上下文——V0.2 做"项目记忆"；
- Trae 的模式化入口（通用/写作/幻灯片）——V0.2 做任务模板，但模板只影响提示词，不改变权限。

**要躲的坑**：
- 积分黑箱 → 我们直接把单价和用量摊开；
- 目录一次性授权 → 我们默认最小授权 + 越界拒绝；
- 插件市场质量参差 → MCP 一律高风险审批，不做"一键信任"。
